# ルーブル、はじめての一日

日本語の非公式セルフガイド。既存の解析コードとは独立した静的ウェブアプリです。

## 起動

Node.js 20以上で `npm run dev`。依存ライブラリは不要です。`http://127.0.0.1:4173/` を開きます。配布版は `npm run build` で `dist/` に生成し、GitHub Pagesなどの静的ホスティングへ配置します。HTTPSで公開するとオフライン保存が使えます。

公開版は `https://sakai175.github.io/louvre-guide-jp/` です。`main` ブランチへ更新を送信すると、GitHub Actionsがテストとビルドを行い、成功した版を同じURLへ自動公開します。

## データ更新

作品一覧は `src/works.json`、検索と並べ替えは `src/catalog.js` で管理します。元Excelは公開リポジトリに含めず、ローカルの `data/ルーブル音声ガイド_候補200作品.xlsx` に保存します。Excelを更新した場合は `powershell -ExecutionPolicy Bypass -File .\scripts\import-works.ps1` で再取り込みできます。別の場所に置く場合は `-Workbook` でパスを指定します。既存の作品IDと展示室情報を保持し、Excel由来の作品の作者・解説・出典を更新します。作品名を変更すると別作品として追加されるため、その場合は `src/works.json` のIDを照合してください。

Excelには部屋番号がないため、新規作品の位置は未確認です。確認できた部屋番号・階・翼は `src/works.json` に記録し、`locationPrecision` を `room` に変更します。`verified` と出典も確認後に更新してください。時間別の訪問順は `src/routes.json` で管理し、展示室の確認とルート追加は別作業です。

音声ファイルは `public/audio/` に置きます。Excelから追加した作品には標準版1本、従来の12作品には4種類の長さがあります。Windowsの日本語SAPI音声が使える環境で `powershell -ExecutionPolicy Bypass -File .\generate-audio.ps1` を実行すると、欠けているWAVだけを生成します。原稿を変更した作品の音声を更新する場合は、その作品の古いWAVを除いてから再生成してください。

## 画面とルート

MAPでは90・120・150・180分の固定ルートに含まれる作品を表示します。AUDIOでは登録済み203作品の音声を一覧表示し、作品名・作者・部屋番号で検索できます。作品名と部屋番号は昇順・降順に並べ替えられ、部屋番号未確認の作品は末尾に置かれます。SETTINGには訪問前の公式確認先を掲載しています。

## 制約

Excel由来の新規191作品は展示室未確認で、時間別ルートや地図には追加していません。位置と開室状況は公式情報で再確認が必要です。マップは公式フロアマップを参考に再構成した独自模式図で、通路形状・作品位置・移動時間・階段利用は実地検証されていません。音声のオフライン保存はブラウザのCache Storageを使い、端末の空き容量やブラウザ設定によって消去される可能性があります。作品画像は利用していません。
