# Louvre Audio Map

日本語の非公式ルーブル美術館セルフガイド。既存の解析コードとは独立した静的ウェブアプリ（PWA）です。

## 起動とビルド

Node.js 20以上で `npm run dev`（依存ライブラリ不要）。`http://127.0.0.1:4173/` を開きます。
配布版は `npm run build` で `dist/` に生成し、GitHub Pages などの静的ホスティングへ配置します。HTTPSで公開するとオフライン保存（Service Worker + Cache Storage）が使えます。

公開版は `https://sakai175.github.io/louvre-guide-jp/` です。`main` ブランチへ更新を送信すると、GitHub Actions がテストとビルドを行い、成功した版を同じURLへ自動公開します。

## 主な画面と機能

- **アプリ名の変更**: `src/app-config.js` の `APP_NAME`（および `index.html`, `public/manifest.webmanifest`）から一括変更できます。
- **下部4タブナビゲーション**: 片手操作に最適化した `マップ` / `プラン一覧` / `音声一覧` / `案内・設定`。
- **マップ**: 5階層（2階〜−2階）の2Dフロアマップ上で、展示室・経路グラフ確認済みの **60作品**（26展示室）をピン表示（同室複数作品は件数バッジ付き1マーカーに集約し、タップで部屋内の全作品を切替閲覧可能）。別階の目的地がある場合はワンタップ階切替バーを表示します。道に迷ったときの部屋番号入力による手動現在地修正にも対応。
- **プラン一覧 & マイプラン**: 90・120・150・180分の固定4コースに加え、全203作品から ☆/★ で自由に組み替えられる **マイプラン**（上下並べ替え・削除・展示室確認済み作品の自動経路案内）と鑑賞済み進捗管理、コース音声の一括オフライン保存に対応。
- **音声一覧（全203作品）**: 作品名・作者・部屋番号・翼名での検索、絞り込み（すべて / 展示室あり / 超有名 / マイプラン）、並び替え（おすすめ順・作品名・部屋番号）。
- **常駐ミニプレイヤー & 作品詳細ボトムシート**: 解説テキストを見ながら操作できるシークバー、±10秒スキップ、再生速度切替（0.75x〜2.0x）、長さ切替（対応作品）、Media Session API（ロック画面操作）、ルート再生連動の現在地自動更新（元に戻す通知付き）。

## データ更新

- 作品一覧は `src/works.json`、検索・絞り込み・並べ替えは `src/catalog.js`、マイプラン計算は `src/my-plan.js`、経路グラフは `src/navigation-graph.json` で管理します。
- 元Excelはローカルの `data/ルーブル音声ガイド_候補200作品.xlsx` に保存し、`powershell -ExecutionPolicy Bypass -File .\scripts\import-works.ps1` で再取り込みできます。
- 音声ファイルは `public/audio/` に配置します（Windows SAPIで `generate-audio.ps1` により不足WAVを生成）。
- 作品画像は `public/images/`、`src/artwork-images.json`、`src/image-credits.json` で管理します。オンライン環境で `node scripts/fetch-artwork-images.mjs` を実行すると、追加確認済み作品の Wikimedia Commons サムネイル画像と出典を一括取得できます（未取得作品も翼カラーごとのプレースホルダーに自動フォールバックします）。

## 制約

- 展示室確認済み61作品（うち60作品がマップ・経路対応）以外の142作品は展示室未確認のため、音声一覧・マイプランでの音声鑑賞対象となります。
- 位置と開室状況は変更される可能性があるため、当日は公式情報と館内表示を優先してください。
- マップは公式フロアマップを基準に再構成した独自模式図で、通路形状・作品位置・移動時間・階段利用は実地検証されていません。
- 音声のオフライン保存はブラウザの Cache Storage を使い、端末の空き容量やブラウザ設定によって消去される可能性があります。
